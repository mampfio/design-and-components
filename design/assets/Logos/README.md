# Logos

All logos are full-colour SVGs with fixed colours and no currentColor. The wordmark is drawn as outlines (Baloo 2 ExtraBold), so it needs no web font.

- `mampfio-lockup.svg`: mark plus wordmark in `ink` (#3A1530), for light grounds.
- `mampfio-lockup-reversed.svg`: wordmark in cream (#FFF4E8), for dark grounds.
- `mampfio-mark.svg`: the mark alone, at least 32 px tall.
- `mampfio-app-icon.svg`: the mark on cream, corners `radius-l` (24 on 100).
- `mampfio-wordmark.svg`: the wordmark alone in `ink`.

Clear space: a quarter of the mark's height. Never place on `brand-berry` or `action`.
