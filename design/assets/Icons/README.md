# Icons

Mampfio uses a selection of [Lucide](https://lucide.dev) icons: line icons (outlined, not filled) on a 24 px grid with 2 px lines and rounded ends, the brand book's icon style.

Icons draw in `currentColor`, so they take the text colour: <dfn title="Design-system name for the text colour.">`ink`</dfn> on surfaces, <dfn title="The text or icon colour that stays readable on top of the named colour.">`on-action`</dfn> on primary buttons. Only the icons listed here are part of the design system. Each has one meaning; don't use an icon for something else.

## Ordering

- `shopping-basket.svg`: Basket (Warenkorb), with the item count as a count badge (`.mf-badge-count`).
- `plus.svg`: Add one more of a dish.
- `minus.svg`: Remove one of a dish.
- `trash-2.svg`: Remove a dish from the basket.
- `receipt-text.svg`: Order and order history (Bestellung). Not `receipt`, which shows a dollar sign.

## Food and restaurants

- `pizza.svg`: Pizza as a cuisine filter. Not a replacement for the logo.
- `utensils.svg`: Restaurant or cuisine in general.
- `chef-hat.svg`: Kitchen view in the restaurant backoffice.
- `star.svg`: Rating (Bewertung).
- `heart.svg`: Favourite restaurant or dish.

## Delivery

- `bike.svg`: Rider on the way (Lieferung).
- `map-pin.svg`: Delivery address.
- `clock.svg`: Delivery time.
- `phone.svg`: Call the restaurant or the rider.

## Status

- `circle-check.svg`: Success, always with text (alert-success).
- `circle-alert.svg`: Error, always with text (alert-danger).

## Navigation and actions

- `search.svg`: Search.
- `funnel.svg`: Filters.
- `menu.svg`: Open the navigation on small screens.
- `arrow-left.svg`: Back.
- `chevron-right.svg`: Go to a detail page.
- `chevron-down.svg`: Expand, dropdown.
- `x.svg`: Close, remove a filter.
- `check.svg`: Selected, done.
- `user.svg`: Account and login.
- `sun.svg`: Switch to the light theme.
- `moon.svg`: Switch to the dark theme.
