# Logos

All logos are full-colour SVGs with fixed colours and no currentColor. The <dfn title="The brand name drawn as a fixed graphic, not set as live text.">wordmark</dfn> is Baloo 2 ExtraBold converted to vector paths, so it needs no web font.

- `mampfio-lockup.svg`: the <dfn title="Mark and wordmark in a fixed arrangement, used as one unit.">lockup</dfn>, <dfn title="The logo's symbol on its own, without the name.">mark</dfn> plus wordmark in <dfn title="Design-system name for the text colour.">`ink`</dfn> (#3A1530), for light backgrounds.
- `mampfio-lockup-reversed.svg`: the <dfn title="Logo variant in light colours for dark backgrounds.">reversed</dfn> lockup, wordmark in cream (#FFF4E8), for dark backgrounds.
- `mampfio-mark.svg`: the mark alone, at least 32 px tall.
- `mampfio-app-icon.svg`: the mark on cream, corners `radius-l` (24 on 100).
- `mampfio-wordmark.svg`: the wordmark alone in `ink`.
- `mampfio-favicon.svg`: the mark simplified for 16 px browser tabs. No teeth or crumbs, one pepperoni, thicker lines, drawn on a 16 × 16 grid.

<dfn title="Minimum empty margin around the logo that no other element may enter.">Clear space</dfn>: a quarter of the mark's height. Never place on `brand-berry` or `action`.
